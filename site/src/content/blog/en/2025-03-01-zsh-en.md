Zsh is powerful and highly customizable. With a few plugins (e.g. Oh My Zsh), you can get a smooth dev experience. This guide covers install, Oh My Zsh, and a dev-oriented config.

## Install

- **macOS**: Zsh is default; update with `brew install zsh` if needed.
- **Ubuntu/Debian**: `sudo apt update && sudo apt install zsh`

Set as default: `chsh -s $(which zsh)`.

## Oh My Zsh

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

Then enable plugins and themes in `~/.zshrc`.

## Zsh frameworks: Zinit recommended

| Framework | Notes | Startup |
| --- | --- | --- |
| Oh My Zsh | Largest ecosystem, works out of the box | Slow (0.5s–2s+) |
| **Zinit** | Only manager with turbo (deferred) loading; async, non-invasive | **Fastest with turbo on** |
| Antidote | Static generated load file, pure Zsh, simplest config | Fast without turbo |
| Prezto | Older, config-heavy | Medium |
| Antigen | Long-standing manager, one `antigen bundle` line per plugin, lazy loading | Medium (maintenance) | People with existing Antigen configs |

**Why Zinit**: it is the only plugin manager offering **turbo mode** (upstream claims 50–80% faster startup than Oh My Zsh), and you can migrate plugins one at a time instead of rewriting `.zshrc`.

> **Honest caveat**: without turbo/deferred loading, Zinit's raw load time is *not* the best. Independent benchmarks (`rossmacarthur/zsh-plugin-manager-benchmark`, run **without deferred loading**) conclude that "zinit, zplug and zpm have notably bad load time performance", while antidote, sheldon and zimfw are fast at both install and load. So: **speed without fiddling → Antidote; maximum control + turbo → Zinit**. Both are reasonable.

### Zinit (recommended)

```bash
bash -c "$(curl --fail --show-error --silent --location https://raw.githubusercontent.com/zdharma-continuum/zinit/HEAD/scripts/install.sh)"
```

```bash
# in .zshrc, before any plugin declaration
ZINIT_HOME="${XDG_DATA_HOME:-${HOME}/.local/share}/zinit/zinit.git"
source "${ZINIT_HOME}/zinit.zsh"

# install plugins: zinit clones and loads them for you
zinit light zsh-users/zsh-autosuggestions
zinit light zsh-users/zsh-syntax-highlighting
zinit light zsh-users/zsh-history-substring-search

# Oh My Zsh built-in plugins without installing Oh My Zsh
# OMZL:: = oh-my-zsh/lib/, OMZP:: = oh-my-zsh/plugins/
zinit snippet OMZL::git.zsh
zinit snippet OMZP::git/git.plugin.zsh

# turbo loading: load after the first prompt (needs Zsh >= 5.3)
zinit ice wait lucid
zinit light zsh-users/zsh-autosuggestions
```

Useful commands: `zinit light` (load without reporting, faster), `zinit load` (load with reporting — `zinit report` / `zinit unload`), `zinit ice <opts>` (options for the next `light`/`load`/`snippet`), `zinit update --all`, `zinit delete <plugin>`, `zinit list`.

Do **not** use `wait` for `zsh-syntax-highlighting` — it hooks ZLE in real time.

### Oh My Zsh

Built-in plugins: just list them — `plugins=(git docker kubectl npm history z extract)`.

Third-party plugins: clone into `${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/<name>`, then add the name to `plugins`:

```bash
git clone https://github.com/zsh-users/zsh-autosuggestions \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
```

```bash
plugins=(git zsh-autosuggestions zsh-history-substring-search zsh-syntax-highlighting)
```

`zsh-syntax-highlighting` must come last. Themes work the same way: clone into `.../custom/themes/<name>` and set `ZSH_THEME="<name>"`. Oh My Zsh does not auto-update third-party plugins — `git pull` them yourself.

### Antidote

Antidote generates a static load file: instead of managing plugins on every startup, `.zshrc` just sources a pre-generated file — which is why it is fast even without deferred loading.

```bash
git clone --depth=1 https://github.com/mattmc3/antidote.git ${ZDOTDIR:-$HOME}/.antidote
```

```bash
# ~/.zsh_plugins.txt — one plugin per line
zsh-users/zsh-autosuggestions
zsh-users/zsh-syntax-highlighting
ohmyzsh/ohmyzsh path:plugins/git
```

```bash
# .zshrc
source ${ZDOTDIR:-$HOME}/.antidote/antidote.zsh
antidote load   # generates a static file once, then loads it — very fast
```

Re-run `antidote load` after editing `.zsh_plugins.txt`.

### Prezto

Install Prezto itself first (`--recursive` is required — it has submodules):

```bash
git clone --recursive https://github.com/sorin-ionescu/prezto.git "${ZDOTDIR:-$HOME}/.zprezto"
```

Then symlink the `runcoms` config files and restart your terminal:

```bash
setopt EXTENDED_GLOB
for rcfile in "${ZDOTDIR:-$HOME}"/.zprezto/runcoms/^README.md(.N); do
  ln -s "$rcfile" "${ZDOTDIR:-$HOME}/.${rcfile:t}"
done
```

Modules replace plugins. Enable built-ins in `~/.zpreztorc`:

```bash
zstyle ':prezto:load' pmodule 'environment' 'terminal' 'editor' 'history' 'directory' 'utility' 'completion' 'syntax-highlighting' 'prompt'
```

Third-party plugins are cloned into `~/.zprezto/contrib/<name>` (Prezto loads from both `modules/` and `contrib/`; `contrib/` survives Prezto upgrades) and added to the same list. To keep them outside the Prezto repo:

```bash
zstyle ':prezto:load' pmodule-dirs $HOME/.zprezto-contrib
```

For the full plugin list, Python/Node/Go/Rust integration, and troubleshooting, see the [Chinese version](2025-03-01-zsh) of this article.

## Case study: one plugin across frameworks (zsh-completions)

Using [zsh-completions](https://github.com/zsh-users/zsh-completions) — taken from upstream's "Using zsh frameworks" section:

```bash
# Antigen
antigen bundle zsh-users/zsh-completions

# Zinit
zinit light zsh-users/zsh-completions
```

**Oh My Zsh has a gotcha**: do **not** add it to `plugins=(...)` — that causes redundant `.zcompdump` generation ([#603](https://github.com/zsh-users/zsh-completions/issues/603)). Clone it to the custom plugins dir and set `fpath` + `compinit` *before* sourcing Oh My Zsh:

```bash
git clone https://github.com/zsh-users/zsh-completions.git \
  ${ZSH_CUSTOM:-${ZSH:-~/.oh-my-zsh}/custom}/plugins/zsh-completions
```

```bash
# in ~/.zshrc, BEFORE sourcing oh-my-zsh:
fpath+=${ZSH_CUSTOM:-${ZSH:-~/.oh-my-zsh}/custom}/plugins/zsh-completions/src
autoload -U compinit && compinit
source "$ZSH/oh-my-zsh.sh"
```

This avoids running `compinit` twice and noticeably speeds up startup. For Prezto, add it to the `pmodule` list after cloning into `contrib/` or a `pmodule-dirs` directory.
