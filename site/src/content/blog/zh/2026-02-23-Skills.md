一套好的 AI 编程工作流，不是再装一个包，而是让助手在需要时读取正确的 `SKILL.md`。Skill 是可复用的工作流说明：它告诉 Claude Code、OpenCode 等编码助手如何处理特定技术、检查或交付流程；它不是 npm 或 Bun 依赖，也不该被当成 lockfile 中必须全量安装的东西。

本文使用 [ECC](https://github.com/affaan-m/ECC) 的 Skills 集合，以及维护该安装流程的 [Skills CLI](https://github.com/vercel-labs/skills)。本站推荐用 Bun 的 `bunx` 运行 CLI；先看清内容，再按代理和项目的实际需要安装。

## 先检查，再安装 ECC Skills

先列出仓库中可用的 Skills。不要因为有全量安装命令，就跳过这一步。

```bash
# Inspect the repository before installing anything
bunx skills add https://github.com/affaan-m/ECC --list

# Install all ECC Skills
bunx skills add https://github.com/affaan-m/ECC --skill '*'
```

`--skill '*'` 会安装该仓库的完整 Skills 选择。它适合想先获得完整集合的场景，但仍应先检查列表，确认其中的工作流与自己的代理、工具和项目相符。

## 选择运行器和所需范围

本博客以 `bunx` 为推荐选择；如果你的环境使用 npm 或 pnpm，下面的安装方式等价：

```bash
npx skills add https://github.com/affaan-m/ECC --skill '*'
pnpm dlx skills add https://github.com/affaan-m/ECC --skill '*'
```

全量安装不是唯一选项。要为特定代理安装单个 Skill，可以使用支持的选择性安装模式：

```bash
bunx skills add https://github.com/affaan-m/ECC --skill <skill-name> -a opencode
```

把 `<skill-name>` 换成检查列表后选定的名称，并按实际使用的代理替换 `opencode`。并非每个 Skill 都适用于每个代理或项目：选择能解决当前工作流问题的那一部分即可。

## Rust 项目额外安装 Rust Skills

Rust 项目可以在 ECC 工作流之外，再安装 [Rust Skills](https://github.com/leonardomso/rust-skills)：

```bash
bunx skills add https://github.com/leonardomso/rust-skills --skill '*'
```

这是针对 Rust 项目的补充安装，不是 ECC 的替代方案。是否安装仍取决于项目是否需要这套 Rust 专项工作流。

## 有意识地更新

Skills 会变化，更新前后都应检查项目需要的范围，并保留正常的工程验证。本站 Bun 项目优先使用：

```bash
# Recommended for this Bun-based project
bunx skills update

# Equivalent runners
npx skills update
pnpm dlx skills update
```

更新不会替代代码审查或项目自身的质量门槛。Skill 提供的是助手执行任务时的可复用说明，最终仍由仓库的格式化、lint 和测试来验证改动。

## 简要检查清单

- [ ] 先检查可用 Skills
- [ ] 只安装当前代理和项目需要的 Skills
- [ ] 项目是 Rust 时，再安装 Rust Skills
- [ ] 有意识地更新，而不是盲目全量升级
- [ ] 继续运行仓库自己的 formatter、linter 和测试
